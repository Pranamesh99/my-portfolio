# Deepak — Premium Portfolio & Static Admin Panel

A production-grade, cinematic portfolio designed for **Kotipalli Pranamesh Sri Durga Deepak**, B.Tech student in **Computer Science** at **Vellore Institute of Technology (VIT)**. Built with React 19, Vite, Tailwind CSS v4, and Framer Motion, featuring a database-free static Admin Panel for non-technical content management.

## 🚀 Key Highlights

- **Visual Theme & Aesthetic**: High-contrast, studio-grade crimson (`#f50604`), deep dark canvas (`#0a0101`, `#0d0101`), clean typography.
- **100% Verified Profile**: Accurate academic representation (VIT Vellore Undergrad, Class 12: 87%, Class 10: 100%).
- **Cinematic Hero**: Sleek static background poster with responsive headline, floating verified metric cards, and downloadable resume.
- **Interactive Lanyard ID Badge**: 3D drop-bounce swinging physics animation in the About section holding Deepak's illustrated portrait.
- **Interactive Cursor Canvas**: Hardware-accelerated 2D canvas with mouse-following crimson sparks and radial spotlight.
- **Building Next Bento Grid**: Project roadmap showcase with interactive case study modals for GenAI & Backend projects.
- **Database-Free Static Admin Panel**: Non-technical dashboard with password protection, real-time localStorage persistence, backup export/import, and factory reset.

## ⚙️ Client Admin Panel Guide 

Deepak can customize this portfolio at any time without touching code, editing JSON, or needing a database.

### 🚪 How to Open the Admin Panel
- **Footer Button**: Scroll to the footer and click the ⚙️ icon next to the "Get in Touch" button.
- **Keyboard Shortcut**: Press `Ctrl + Shift + A` (or `Cmd + Shift + A` on Mac) anywhere on the website.
- **URL Hash**: Add `#admin` to the end of the website URL (e.g., `http://localhost:5173/#admin`).

### 📝 What You Can Edit
- **Identity & Contact**: Name, title, university, current semester, location, phone number, and email.
- **Hero**: Welcoming greeting, headline, subtitle, and CTA buttons.
- **Stats & Facts**: CGPA, DSA problems, hackathon achievements, etc.
- **About Me**: Biography description and headline.
- **Projects**: Project titles, categories, duration, badges, descriptions, and case study details.

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Pranamesh99/my-portfolio.git

# Navigate to the folder
cd my-portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```
